# 山河长明：发布架构与维护边界

作者署名：禁忘记历史。更新于2026年11月4日。

## 页面与内容

首页包括纪念点烛、七章历史故事、分期索引、按需追加的事件时间线和全屏幻灯展映。独立页面包括中国节日、收录说明、隐私说明与意见反馈。React共用组件同时生成GitHub Pages静态站和Sites版本，使用各自正确的资源路径。

187条事件保存在源码`data/catalog.json`，由`catalog.lock.json`锁定数量与SHA-256。检索与只读目录接口使用同一快照，不从数据库加载可编辑历史。当前只覆盖1840—1949年选定主题，不能称为全部历史事件。7章原创短文附官方来源链接；日期精度受共同证据约束。

节日按北京时间识别，通过中国农历转换识别传统节日；清明、冬至采用香港天文台2024—2040年表。超出对照表范围不推算节气日期。多个节日同日全部显示，纪念日优先配色，国庆优先于普通传统节日。页面在北京时间零点、恢复前台和窗口聚焦时刷新主题。民俗日期采用通行口径，地区习俗可能不同。

## 播放与素材

展映默认播放全部187条，可在筛选后选择当前结果。提供上一条、下一条、暂停、每页停留时间、配乐开关和音量。读完后展示“写给所有中国年轻人：铭记历史”与作者署名。离开前台暂停，退出恢复滚动；支持Escape、键盘焦点约束及减少动态效果偏好。

配乐为约4分55秒的原创合成器组曲，无外部采样。原生SVG山河背景与蜡烛图标见`public/art/`，明确以CC0 1.0开放；Lucide图标保留ISC许可。回顶部图标仅是原创示意造型，所用型号与年份来自已公开官方资料，非技术图纸或完整型号序列。

## 点烛数据

GitHub Pages页面通过HTTPS访问Sites的点烛API；同源Sites页面使用安全Cookie，跨站静态页面使用随机匿名令牌。数据库仅保存令牌摘要。历史目录与点烛记录分开；发布界面不重置数据库。北京时间自然日与访客摘要的唯一约束防止同一浏览器当天重复计数，幂等键与原子批处理防止重试、并发重复写入。数字为有效点烛次数，不代表独立自然人数；清除浏览器数据可改变匿名身份。

只在主动点击并确认成功后亮烛。没有演示次数或预置人数。自动化写入验证必须使用独立临时数据库，拒绝生产地址与5173交互预览端口。

## 反馈与人工审校

反馈在浏览器内生成GitHub Issue草稿，用户登录GitHub并自行确认提交。类型包括史实修改、补充事件与网站意见。前两类要求两条资料链接。网站不抓取提交的URL、不保存联系方式、不自动发布建议，不设置历史编辑后台。两条链接本身不等于通过审校；必须实际阅读原文、辨别同稿转载、交叉核对日期与名称后，才能修改源码并发布新版本。

## 安全控制

- API对写操作校验来源；跨域只允许配置的GitHub Pages来源，拒绝通配来源。
- 随机访客身份、参数化SQL、每日唯一约束、幂等记录和操作限流共同保护点烛。
- JSON请求按实际读取字节流限制25KB，避免先完整读入超大请求。
- Worker响应加`nosniff`、来源信息限制与摄像头/麦克风/定位权限限制。
- GitHub静态页面通过CSP限制脚本、音频、图片及联网来源，不接受任意脚本或对象嵌入。GitHub Pages无法配置所有自定义响应头，不将其描述为与Worker完全相同。
- 反馈目标固定为项目Issue页，URL参数编码，只允许无凭据的HTTP(S)来源地址。React负责正文转义。
- 发布前执行类型检查、规则测试、隔离HTTP检查、依赖审计与真实浏览器检查。依赖审计结果是当时快照，不是永久安全保证。

2026年11月4日完整依赖审计仍报告25项低/中等级告警（低2、中23），高/严重为0。已修补Next、React服务器组件、Vite、Sharp及相关高风险传递依赖。剩余告警集中在开发工具和未使用的图像生成依赖链，不能因为它们列在开发依赖就一概视为没有运行风险；当前没有开放上传、动态图像生成、Server Function业务或开发服务器到公网。本轮保持框架主版本与数据库结构，后续工具链迁移需要单独回归。公网GitHub Pages只发布静态文件，API由Worker独立提供。

## 发布与回退

先在Sites源码库保存并构建确定版本，再部署已保存版本；相同追踪文件树同步到独立GitHub公开库，由Actions构建Pages。公开镜像只包含当前批准源码，不复制旧私有历史或研究原文。版本出问题可重新部署上一Sites版本或回退GitHub提交；点烛数据库不随源码回退，不自动删除任何真实点烛记录。
