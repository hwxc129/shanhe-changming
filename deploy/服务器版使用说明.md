# 山河长明 · 完整服务器版

作者：禁忘记历史。

包内已经完成构建，无需安装npm依赖，也不需要Cloudflare、D1、Sites账号或原站密钥。事件目录固定，187条事件与七章故事随包提供；不设内容管理后台。

## 推荐：Docker启动

1. 解压，进入包含`compose.yaml`的目录。
2. 复制`.env.example`为`.env`。正式上线把`PUBLIC_ORIGIN`改为自己的HTTPS域名，例如`https://memorial.example.com`。不要填写网页子目录。
3. 执行：

```sh
docker compose up -d --build
```

本机试运行保留默认配置，访问`http://localhost:3000`。服务器部署时，默认端口只开放给服务器本机：在现有网站管理面板或Nginx中，把自己的域名反向代理到`http://127.0.0.1:3000`，并为该域名启用HTTPS。Nginx的代理位置可参考：

```nginx
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $http_host;
}
```

若确实要直接通过服务器IP试用，可将`.env`中的`LISTEN_ADDRESS`改为`0.0.0.0`，并把`PUBLIC_ORIGIN`改为实际访问的`http://服务器IP:3000`。浏览器地址必须与配置一致。完成试用后推荐改回域名与HTTPS。

查看运行状态：`docker compose ps`。查看日志：`docker compose logs --tail=50`。

## 已有Node.js：直接启动

需要支持`node:sqlite`的Node.js 24或以上；推荐使用仍受维护的LTS版本。直接运行：

```sh
node server.mjs
```

默认访问`http://localhost:3000`。正式部署先设置环境变量`PUBLIC_ORIGIN=https://自己的域名`，再启动。可使用`PORT`调整监听端口，`DATA_FILE`指定数据库位置；这些是运行设置，不是源码编辑后台。

## 数据与更新

- Docker版数据保存在`memorial-data`持久卷；直接启动版默认保存到`data/candles.sqlite`。初次启动自动创建自己的空数据库，不附带原站访客或点烛记录。
- 点烛次数只统计本站记录。本浏览器累计通过服务器确认；清除Cookie、换浏览器或换站点来源会形成新的身份，不能视为同一物理设备的永久识别。
- 按北京时间自然日每日一次；并发与重复请求不会重复增加。
- 更新前停止服务并备份完整数据目录，包括可能存在的SQLite辅助文件。替换程序和`public`，保留数据库/持久卷，再启动。不要运行`docker compose down -v`，该命令会删除持久卷。
- 原站D1与此独立SQLite不自动同步。目录更新需重新核对并发布新版包，访客不能修改事件。
- 只部署一个应用实例使用该数据库文件。此轻量版适合个人与小型纪念站，未做大型集群承载验证。

## 放到已有网站

若只想显示入口，打开本站“分享与部署”页面，复制入口HTML到已有网页即可。若只需要静态托管，另下载纯静态版，不要把本服务器版源文件直接放进公开网站目录。
